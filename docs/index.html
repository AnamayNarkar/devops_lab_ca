Download Skyline

One file, no installer. Pick the build that matches your computer.

Linux: after downloading, run chmod +x skyline-weather-linux-* then ./skyline-weather-linux-x64 (or the arm64 file). Downloads lose the executable flag, so your file manager will not open them until you do this.
Windows: the app is unsigned, so SmartScreen may warn. Choose “More info”, then “Run anyway”.
